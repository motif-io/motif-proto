# Motif Protobuf

**motif-proto** contains the set of Protobuf schemas for the **Motif
platform**, published to the Buf Schema Registry as
[`buf.build/motif/platform`](https://buf.build/motif/platform).

For guides and reference on building with Motif, see
**[developers.motif.io](https://developers.motif.io)**.

In this repository:

- [buf.md](buf.md) describes the packages and how to depend on the module.
- [CONTRIBUTING.md](CONTRIBUTING.md) covers adding or changing schemas.

The schemas are licensed under the [MIT License](LICENSE).
